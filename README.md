# Kamirty Anime · استوديو الأنمي العربي

**الموقع:** https://anime.kamirtyai.com

أداة مجانية تعمل بالكامل داخل المتصفح: يكتب الزائر وصف مشهد بالعربية، فتصنع منه مشهد أنمي متحركًا بشخصيات عُمانية وخليجية ومؤثرات صوتية، ويُنزّله فيديو MP4. لا حساب ولا خادم ولا خدمة مدفوعة، ولا يُرفع وصف الزائر أو ملفاته إلى أي مكان.

## طريقتان للعمل
1. **صِف مشهدك:** محلل عربي حتمي يفهم المكان والوقت والشخصيات واللبس والألوان والحركات والتعابير والتأثيرات والمناسبات، والكلام بين «» أو بعد كلمة «عبارة». يطبّق قواعد الإخراج تلقائيًا: لقطة افتتاحية واسعة، ثم الاقتراب، ثم الحدث، ثم الختام. لا يخترع ما لم يُكتب، ويعرض الكلمات التي لم يفهمها.
2. **مشهد حرّ مع Claude:** للأفكار التي ليست في المكتبة. تنسخ الأداة طلبًا جاهزًا يلصقه الزائر في Claude بحسابه هو. يرد Claude بملف مشهد JSON قد يتضمن رسومات جديدة بمسارات SVG، فتتحقق الأداة منه وتعرضه وتصدّره فيديو. لا يُشغَّل أي كود من الرد.

## المكتبة
- **9 أماكن** بثلاثة أوقات (نهار، غروب، ليل): قلعة، صحراء، بحر وشاطئ، جبال ووادٍ، مزرعة نخيل وفلج، مدينة، فصل دراسي، مجلس البيت، فضاء.
- **4 أنواع شخصيات** (ولد، بنت، رجل، امرأة) بثمانية أزياء:
  - دشداشة وكمّة مطرّزة.
  - دشداشة ومصرّ عُمانية: لفّة قماش بحاشية مطرّزة، ولفّة ملتوية فوق الحاجب، وطرف مطويّ فوق الأذن.
  - ثوب وغترة وعقال.
  - عباءة وشيلة.
  - زي عُماني تقليدي بلحاف وسروال مطرّز.
  - زي مدرسي.
  - لبس عادي.
  - معطف مختبر.

  ولكل شخصية أربع درجات للبشرة، وألوان لبس قابلة للتغيير.
- **11 حركة** مرسومة على طريقة الأنمي، كل رسمة تُعرض إطارين:
  - يقف، يمشي، يلوّح، يتكلم، يشير، يرحّب، يفكّر، يصفّق، يحتفل، يقفز.
  - ضربة قوة كاملة: تحفّز، ثم قفزة، ثم دوران، ثم هلال من نور، ثم إطار صدمة، ثم تشقّق الهدف.
- **6 تعابير** للوجه.
- **9 تأثيرات:** ألعاب نارية، قصاصات، بالونات، أشرطة بألوان علم عُمان، لمعان، شهب، مطر، غبار، خطوط سرعة.
- **الكاميرا:**
  - لقطة واسعة أو متوسطة أو قريبة، مع عمق متعدد الطبقات.
  - اقتراب بطيء أو حركة جانبية.
  - الانتقال بين اللقطات بإظلام أو ومضة أو قطع مباشر.
- **النصوص:** فقاعات كلام، وشريط سفلي، وعنوان كبير، بعشرة خطوط عربية مستضافة على الموقع نفسه.

## أدوات المحترفين (الوضع «احترافي»)
- **وضع المخرج:** حركة كاميرا ببداية ونهاية لكل لقطة (تقريب، تحريك يمين ويسار، أعلى وأسفل)، مع سرعة الحركة واهتزاز اختياري، وقوالب جاهزة: اقتراب درامي، ابتعاد كاشف، تحريك أفقي، صعود، هزّة صدمة.
- **الوضعية المخصصة بالمفاصل:** حركة «وضعية مخصصة» يسحب فيها المستخدم المرفق واليد (والركبة والقدم للبس العادي)، ويضبط ميل الرأس والجسم وانحناء الركبتين، مع وضعية أولى وأخيرة تتحرك الشخصية بينهما على اثنين ثم تثبت.
- **تصدير الطبقات:** زر «🗂 طبقات» يحفظ الإطار الحالي ملف ZIP فيه صور PNG شفافة للخلفية والشخصيات والمؤثرات والنصوص. ومن نافذة التصدير: فيديو لكل طبقة على خلفية خضراء لبرامج المونتاج (After Effects وPremiere)، وملف JSON بحجم الكاميرا وموضعها في كل إطار.

## مختبر الحركة (داخل الاستوديو)
زر «🎓 مختبر الحركة» يفتح تبويبين:

- **مكتبة الحركات (100):** في ستّ فئات:
  - **حركات يومية (16):** مشي وركض وقفز ورقص وترحيب ومصافحة وانحناءة وجلوس وتمدّد وتلفّت وتقديم القهوة بالدلّة.
  - **تواصل وإشارات (20):** إشارة ونداء وهمس وإنصات وطلب هدوء ورفض ودعوة وعرض وتحية عسكرية ورفع اليدين.
  - **تعليم ومدرسة (18):** قراءة كتاب، وكتابة على السبورة وفي الدفتر، ورفع اليد للإجابة، والإشارة بالمؤشر، وتسليم ورقة وتصحيحها، وتجربة المختبر، والميكروفون، وزراعة شتلة، ورفع العلم.
  - **مشاعر وحالات (16):** دعاء، ويد على القلب، وبكاء، وضحك، وخجل، وخوف، وفخر، وتعب، وغضب، وأمل، وفكرة.
  - **رياضة وحماس (14):** تصفيق واحتفال ونصر وتمارين ولكمة ووضعية استعداد وضربة القوة.
  - **حركات الكاميرا (16):** اقتراب وابتعاد وتحريك وصعود ونزول وهزّة وتوتر واستقرار.

  يختار المستخدم الحركة ويشاهدها في معاينة حيّة على شخصياته، ثم يطبّقها على اللقطة الحالية أو على كل اللقطات، ولشخصية واحدة أو للجميع. تتغيّر الحركة وحدها؛ أما المكان والشخصيات واللبس والنصوص والتأثيرات فتبقى كما هي، ويمكن التراجع بـ Ctrl+Z.
- **الأسلوب:** رسم مسطّح بلا حدود سوداء حول الجسم أو الملابس أو الكفّ؛ تُفصَل الأشكال بحافة من لونها نفسه أغمق قليلًا، وتبقى ملامح الوجه مرسومة.
- **الكفّان:** لكل حركة شكل يدٍ مناسب — كفّ مفتوح، أو مبسوط، أو قبضة، أو إصبع يشير، أو قبضة تمسك — ويدور الكفّ مع اتجاه الساعد، ويُرسم فوق الرأس حين تلمس اليد الوجه.
- **أشياء في اليد:** تحمل الحركة ما يناسبها: كتاب، وورقة، وقلم، ومؤشّر، ودورق، وكرة، وعلم، وفنجان، ودلّة، وميكروفون، وهاتف، وشتلة.
- **دروس التحريك (8):** ثمانية دروس تفاعلية في مبادئ تحريك الأنمي: الرسم على اثنين، والتحفّز، والتسارع والتباطؤ، ورسمة السرعة، والثبات، ورموز الأنمي، وحجم اللقطة، وإطار الصدمة. وزر «طبّق الدرس» يبني مشهدًا في الاستوديو يطبّق المبدأ.

## الصوت
كل الأصوات مولّدة بالكود داخل المتصفح، بلا عينات صوتية ولا حقوق:
- **أصوات المكان:** ريح، وموج، وطيور، وصراصير الليل، وأجواء الغرفة.
- **مؤثرات متزامنة مع الإطارات:** الخطوات، والتصفيق، والضربة والتحطّم، وكل لعبة نارية.
- **موسيقى:** هادئة، أو احتفالية بإيقاع الطبول والتصفيق، أو حماسية.

ويمكن للزائر استبدال الموسيقى بملف صوتي من جهازه.

## التصدير
- **الصيغة:** MP4 (فيديو H.264 مع صوت AAC أو Opus)، أو WebM إذا لم يدعم المتصفح MP4.
- **الجودة:** عادية أو عالية.
- **الأداة:** يتم الترميز عبر Mediabunny وWebCodecs داخل المتصفح.
- **التحقق:** بعد التصدير يُفحص الملف الناتج: المدة، وعدد الإطارات، والأبعاد.

## إضافات الاستوديو المطوّر

- **مستوى الاستخدام:** زر «سهل / احترافي»، ودليل تفاعلي من 3 خطوات. تتيح الواجهة المبسطة وصف المشهد، واختيار مقاس الفيديو، ومعاينته ثم تصديره.
- **مشاريعي:** حفظ حتى 12 نسخة مستقلة في مساحة المتصفح المحلية، مع فتحها أو حذفها. لا يُعد ذلك نسخة احتياطية سحابية، وقد يحذف المتصفح البيانات. يُنصح بتنزيل ملفات `.anime.json`.
- **الشخصيات:** معاينة مرسومة لكل شخصية، وقوالب أزياء عُمانية قابلة لتغيير الألوان والملامح ونوع الشخصية. يتم الاحتفاظ بهوية الشخصية عبر لقطاتها.
- **حركات إضافية:** الركض والرقص وهز الرأس، مع محلّل وصف عربي يدعم كلماتها.
- **الصوت:** تسجيل من الميكروفون أو استيراد ملف لكل لقطة، مع مزج الصوت في توقيت اللقطة. يمكن تحريك الفم وفق **شدة الصوت** المسجّل (ليس تحليلًا للحروف الصوتية ولا مزامنة شفاه دقيقة). التسجيلات تبقى في الذاكرة لهذه الجلسة **ولا تدخل في ملف JSON أو مكتبة المشاريع**؛ صدّر الفيديو قبل إغلاق الصفحة.
- **تصدير إضافي:** صورة PNG عالية الدقة للإطار الحالي، وGIF لأوّل 4 ثوانٍ بحد أقصى 360 بكسل و8 إطارات/الثانية **بلا صوت**، ولوحة مشاهد قابلة للطباعة عبر أمر «حفظ PDF» في المتصفح.
- **الاعتمادية:** إصلاح حفظ نسخة احتياطية من الحفظ التلقائي عند تعطل المحرر، تحسين اختيار دقة تصدير الفيديو على الشاشات الصغيرة، ومنع تشغيل ملفات الصوت الطويلة جدًا.
- **التحقق:** `.github/workflows/ci.yml` يشغّل فحص TypeScript والاختبارات وبناء الإنتاج عند طلبات الدمج.

> تختلف إمكانات MP4/WebM والصوت والتسجيل حسب دعم المتصفح. في المتصفحات التي لا تدعم ترميز الفيديو يمكن استخدام صور PNG، GIF، أو لوحة القصة. يُنصح بتجربة التصدير على الجهاز المقصود قبل إعداد مشروع طويل.

## التطوير
```bash
npm ci
npm run dev        # خادم التطوير
npm run typecheck
npm test
npm run build      # الملفات الثابتة في dist/
```
صفحات معاينة الرسوم للمطورين: `/dev/gallery.html?sheet=chars|places|power`.

## النشر
- عند كل دمج في `main` يعمل `.github/workflows/deploy.yml`: يفحص ويختبر ويبني، ثم ينشر `dist/` إلى الفرع `gh-pages` على النطاق `anime.kamirtyai.com`.
- إعداد DNS (مثل موقع الموشن): سجل `CNAME` باسم `anime` يشير إلى `kamirty.github.io`.

## البنية
```
src/domain/            نموذج المشروع والتوقيت والتنقية
src/design/            الخطوط
src/engine/art/        الرسوم: الرأس والجسم والحركات والأماكن والتأثيرات والأشياء في اليد
src/engine/art/reach.ts  حساب زوايا الذراع من موضع اليد المطلوب (حتى تقع اليد على الصدر أو الذقن فعلاً)
src/engine/motions.ts  مكتبة المئة حركة
src/engine/renderer/   renderFrame الحتمي (للمعاينة والتصدير) والنصوص العربية
src/engine/parser/     محلل الوصف العربي وطلب Claude
src/engine/audio/      توليد الأصوات والموسيقى
src/engine/export/     التصدير والتحقق
src/app/               الواجهة العربية
```
راجع `THIRD_PARTY_LICENSES.md`.

## فيلم التعريف
`dev/promo.html` فيلم إعلاني رأسي (1080×1920، ٣١ ثانية) بكتابة حركية عربية بالأبيض والأسود، وكل لقطات الأنمي داخله يرسمها `renderFrame` نفسه، وموسيقاه ومؤثراته مولّدة بالكود. يفتح في المتصفح للمعاينة، ويُصوَّر إطارًا إطارًا إلى MP4 عبر Playwright وffmpeg.
