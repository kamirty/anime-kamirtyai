# Kamirty Anime · استوديو الأنمي العربي

**الموقع:** https://anime.kamirtyai.com

أداة مجانية تعمل بالكامل داخل المتصفح: يكتب الزائر وصف مشهد بالعربية، فتصنع منه مشهد أنمي متحركًا بشخصيات عُمانية وخليجية ومؤثرات صوتية، ويُنزّله فيديو MP4. لا حساب ولا خادم ولا خدمة مدفوعة، ولا يُرفع وصف الزائر أو ملفاته إلى أي مكان.

## طريقتان للعمل
1. **صِف مشهدك:** محلل عربي حتمي يفهم المكان والوقت والشخصيات واللبس والألوان والحركات والتعابير والتأثيرات والمناسبات، والكلام بين «» أو بعد كلمة «عبارة». يطبّق قواعد الإخراج تلقائيًا: لقطة افتتاحية واسعة، ثم الاقتراب، ثم الحدث، ثم الختام. لا يخترع ما لم يُكتب، ويعرض الكلمات التي لم يفهمها.
2. **مشهد حرّ مع Claude:** للأفكار التي ليست في المكتبة. تنسخ الأداة طلبًا جاهزًا يلصقه الزائر في Claude بحسابه هو. يرد Claude بملف مشهد JSON قد يتضمن رسومات جديدة بمسارات SVG، فتتحقق الأداة منه وتعرضه وتصدّره فيديو. لا يُشغَّل أي كود من الرد.

## المكتبة
- **9 أماكن** بثلاثة أوقات (نهار، غروب، ليل): قلعة، صحراء، بحر وشاطئ، جبال ووادٍ، مزرعة نخيل وفلج، مدينة، فصل دراسي، مجلس البيت، فضاء.
- **4 أنواع شخصيات** (ولد، بنت، رجل، امرأة) بثمانية أزياء:
  - دشداشة وكمّة مطرّزة.
  - دشداشة ومصرّ.
  - ثوب وغترة وعقال.
  - عباءة وشيلة.
  - زي عُماني تقليدي بلحاف وسروال مطرّز.
  - زي مدرسي.
  - لبس عادي.
  - معطف مختبر.

  ولكل شخصية أربع درجات للبشرة، وألوان لبس قابلة للتغيير.
- **11 حركة** مرسومة على طريقة الأنمي، كل رسمة تُعرض إطارين:
  - يقف، يمشي، يلوّح، يتكلم، يشير، يرحّب، يفكّر، يصفّق، يحتفل، يقفز.
  - ضربة قوة كاملة: تحفّز، ثم قفزة، ثم دوران، ثم هلال من نور، ثم إطار صدمة، ثم تشقّق الهدف.
- **6 تعابير** للوجه.
- **9 تأثيرات:** ألعاب نارية، قصاصات، بالونات، أشرطة بألوان علم عُمان، لمعان، شهب، مطر، غبار، خطوط سرعة.
- **الكاميرا:**
  - لقطة واسعة أو متوسطة أو قريبة، مع عمق متعدد الطبقات.
  - اقتراب بطيء أو حركة جانبية.
  - الانتقال بين اللقطات بإظلام أو ومضة أو قطع مباشر.
- **النصوص:** فقاعات كلام، وشريط سفلي، وعنوان كبير، بعشرة خطوط عربية مستضافة على الموقع نفسه.

## الصوت
كل الأصوات مولّدة بالكود داخل المتصفح، بلا عينات صوتية ولا حقوق:
- **أصوات المكان:** ريح، وموج، وطيور، وصراصير الليل، وأجواء الغرفة.
- **مؤثرات متزامنة مع الإطارات:** الخطوات، والتصفيق، والضربة والتحطّم، وكل لعبة نارية.
- **موسيقى:** هادئة، أو احتفالية بإيقاع الطبول والتصفيق، أو حماسية.

ويمكن للزائر استبدال الموسيقى بملف صوتي من جهازه.

## التصدير
- **الصيغة:** MP4 (فيديو H.264 مع صوت AAC أو Opus)، أو WebM إذا لم يدعم المتصفح MP4.
- **الجودة:** عادية أو عالية.
- **الأداة:** يتم الترميز عبر Mediabunny وWebCodecs داخل المتصفح.
- **التحقق:** بعد التصدير يُفحص الملف الناتج: المدة، وعدد الإطارات، والأبعاد.

## التطوير
```bash
npm ci
npm run dev        # خادم التطوير
npm run typecheck
npm test
npm run build      # الملفات الثابتة في dist/
```
صفحات معاينة الرسوم للمطورين: `/dev/gallery.html?sheet=chars|places|power`.

## النشر
- عند كل دمج في `main` يعمل `.github/workflows/deploy.yml`: يفحص ويختبر ويبني، ثم ينشر `dist/` إلى الفرع `gh-pages` على النطاق `anime.kamirtyai.com`.
- إعداد DNS (مثل موقع الموشن): سجل `CNAME` باسم `anime` يشير إلى `kamirty.github.io`.
